# Lessons

One short lesson per run (newest last). Read before searching; apply to the next run's query list.

- 2026-10-08 (first run): Most Spanish calls found by search had already closed for 2026 (FECYT 16 Sep, NEOTEC 14 May, CaixaResearch Health Nov 2025). Track them as `closed` or `expected` so the dashboard shows when to prepare for 2027. Calls with open deadlines right now were all EU: COST (28 Oct), NLnet (3 Nov), EIC (4 Nov).
- 2026-10-08: Pages that work with WebFetch: cost.eu, nlnet.nl, eic.ec.europa.eu, and the enisa.es startups page. BOE and COST PDFs come back as binary; save them and run `pdftotext`. caixaresearch.org returns 403, and the old ENISA line URL returns 404. The Funding & Tenders portal needs JavaScript, so use Euresearch / national contact point alerts as the secondary source and mark those rows unverified.
- 2026-10-08: Gaps for next run: Cloudy has no open call yet. Search Comunidad de Madrid and Ayuntamiento de Madrid culture/science outreach grants, Ministerio de Juventud e Infancia, Creative Europe, and children's book prizes.
