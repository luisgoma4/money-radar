# Lessons

One short lesson per run (newest last). Read before searching; apply to the next run's query list.

- 2026-10-08 (first run): Most Spanish calls found by search had already closed for 2026 (FECYT 16 Sep, NEOTEC 14 May, CaixaResearch Health Nov 2025). Track them as `closed` or `expected` so the dashboard shows when to prepare for 2027. Calls with open deadlines right now were all EU: COST (28 Oct), NLnet (3 Nov), EIC (4 Nov).
- 2026-10-08: Pages that work with WebFetch: cost.eu, nlnet.nl, eic.ec.europa.eu, and the enisa.es startups page. BOE and COST PDFs come back as binary; save them and run `pdftotext`. caixaresearch.org returns 403, and the old ENISA line URL returns 404. The Funding & Tenders portal needs JavaScript, so use Euresearch / national contact point alerts as the secondary source and mark those rows unverified.
- 2026-10-08: Gaps for next run: Cloudy has no open call yet. Search Comunidad de Madrid and Ayuntamiento de Madrid culture/science outreach grants, Ministerio de Juventud e Infancia, Creative Europe, and children's book prizes. SEMF: find out whether the Valencia summer school can get Generalitat Valenciana or Ayuntamiento de València funding.
- 2026-10-09 (BranchOut deep dive): A coworking + coliving hub sits between three funding families. (1) Housing: the Plan Estatal de Vivienda 2026–2030 funds coliving only under 20-year capped-rent protection, and press reports say Madrid won't join the plan. (2) Ecosystem-building: Horizon Startup Europe 2027 and NEB, both consortium-only. (3) Rural: LEADER and demographic-challenge funds, often only for municipalities. Location and legal form decide which family applies; ask for them before searching further. Good sources: comunidad.madrid/inversion/innova (lists the always-open lines), new-european-bauhaus.europa.eu, boe.es/eli for decrees. Next gaps: private real-estate / impact investors for coliving, ICO lines, and the Madrid city council incubator network.
- 2026-10-09 (Madrid West): Municipal calls in Las Rozas, Majadahonda and Pozuelo are published as short BOCM extracts with a BDNS id. Search BOCM + BDNS, save the PDF and run pdftotext. Windows can be very short (Pozuelo culture: 15 days), so registered office and municipal registration must be in place beforehand. Las Rozas lends cultural-centre rooms free, but only to registered cultural associations. Next gaps: Majadahonda and Pozuelo space cession for associations, the Las Rozas 2026–27 cession call, Comunidad de Madrid grants to non-profits, and private patrons / mecenazgo for the foundation.
- 2026-10-09 (winners): The BDNS public API gives award lists by call number with no login: `concesiones/busqueda?numeroConvocatoria=N`. Unknown filter params are silently ignored, which returns every award in Spain. FECYT, CDTI and Majadahonda upload their awards; Pozuelo culture does not. Winner data changed the strategy: FECYT median is EUR 20.5k (ask 15–25k, not 100k), NEOTEC winners max out the PhD-hire cap, Majadahonda Emprende is mostly non-tech local businesses.
- 2026-10-09 (municipalities): Use BDNS to compare councils. Pull all calls of a council with `convocatorias/busqueda` (keyword + filter on nivel2), then the awards. Open culture calls in these towns are small (Las Rozas EUR 20k split evenly). The real municipal money goes through nominative agreements (convenios) with established entities, so track agreements, not only calls. Decreto 11/2018 school-premises use is region-wide and open to non-associations. Still unknown: SEMF's exact registry, and each town's rule for registering a branch (delegación) of an association based elsewhere.
- 2026-10-09 (strategy): First planner pass. M_CERT (certificates and e-signature, about 2 weeks) unlocks the most calls, so do it first. The foundation (about 20 weeks) and the Las Rozas registered office unlock the largest-value municipal path (convenios). SEMF can already apply to FECYT and COST without waiting for the foundation, if its registration is confirmed. COST OC-2026-1 is late (preparation should have started on 16 Sep).
- 2026-10-09 (calendar/graph): The calendar shows, as "late", the start dates and milestones that are already past for EIC, COST and NEB, plus the IDIPHISA partnership. The next hard dates are certificates/e-signature (27 Nov) and the asociación local (13 Jan) to reach the 2027 municipal calls. Causality Graphs is confirmed as a company, and the CSIC PI and UNED partners were added: CaixaResearch Health can now be led by CSIC (neuroscience is one of its areas), with no milestone pending.
- 2026-10-09 (causal layer): The ecosystem is now one DAG for 2D and 3D: factors, partners, entities, faces, products, milestones and calls, with weights. An organisational link ("la fundación agrupa a Causality") created a false cycle through the money flow, so keep organisation and causation apart. Main confounders: fondos propios (16 calls) and sede en Las Rozas (13). Key mediator: Causality Graphs.
- 2026-10-09 (voice oracle): `claude -p --json-schema` returns the reply in `structured_output`. Sonnet answers in about 3.5 s without tools and about 17 s when it reads state; local intents cover the frequent commands instantly. Mutations must go through a server-side preview token so the LLM cannot skip confirmation. Edits to build.py and strategy.json need back-up, monitor and restore: a weight or relation change can create a DAG cycle.
